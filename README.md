# 立替精算チェックツール

各団体・各部署から提出された「処理済みのレシートと精算報告書」を監査・検算（ダブルチェック）し、過不足なく現金精算を行うためのWebツールです。

サーバー構築やソフトのインストールは一切不要で、組織の制限されたPC環境でもブラウザ（Chrome / Edge）で　`index.html` を開くだけで動作します。また、外部サーバーへの通信は一切行わず、すべてのデータは動作PC内のローカルファイル（JSON / CSV）として完結します。

---

## 主な特徴

1. 完全ゼロインストール・ローカル完結
    - Node.js や Python、 データベースソフトなどのインストールは不要です。
    - File System Access API により、PC内の指定したローカルJSONファイルへリアルタイムに自動上書き保存できます。
2. 事前名簿不要・個人情報レス設計
    - 名簿データの事前登録は不要です。チェック作業中にその場で識別名を入力できます。
    - 氏名や所属名を入力したくない場合は、空欄のまま登録すると「担当者1」「担当者2」...と連番を自動採番します。
    - 一度登録した立替担当者はワンクリック選択ボタンとして表示されるため、2枚目以降の入力もスムーズです。
3. 処理済み書類の検算（ダブルチェック特化）
    - 申告額 vs レシート実額 の差額（過大請求・過少請求）をリアルタイムで自動計算・ハイライトします。
    - 配分予算を1円でもオーバーすると警告を表示します。
    - 同じ日付・同じ金額のレシートが登録された際に重複アラートを出します（二重計上防止）。
4. 担当者別支払額の自動合算 ＆ 金種計算（お釣り計算）
    - 監査で確定した「正しい金額」をもとに、立替者担当者ごとの合計立替金額を自動算出します。
    - 全員にお釣りなしでぴったりの現金を渡すために必要な紙幣・硬貨の枚数（1,000円札x枚、 500円玉x枚...）を自動計算します。
    - Excelでそのまま開ける形式（UTF-8 BOM付きCSV・受領サイン欄付き）で一覧表を出力できます。
